# EnTraST

## Overview
This project investigates how fracture networks, stress heterogeneity, and
thermo-hydro-mechanical (THM) processes control induced seismicity in
geothermal reservoirs.

## Objectives

- Develop numerical THM models.
- Quantify stress evolution around injection wells.
- Improve seismic hazard assessment.
